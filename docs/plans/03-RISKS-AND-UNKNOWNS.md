## C. Risks (known, accepted, with mitigations)

| ID | Risk | Mitigation in the plan |
|----|------|------------------------|
| R-01 | Node.js cannot be vendored; a consultant without Node is stopped at the first live-mode step | Design-only needs no Node; the launcher prints the exact per-OS install command; README lists prerequisites first |
| R-02 | Committed `packages/snowarch/dist/` can go stale relative to `src/` | CI rebuilds and `git diff --exit-code`; release script refuses to tag on a diff; contract sha ties dist, manifest and docs to one commit |
| R-03 | Server behaviour changes (SCRIPTING no longer gates reads, precedence inversion, no cwd `.env`, unconfigured start) affect anyone using snow-mcp 1.0.0 outside the Architect | Product 2.0.0 supersedes (R-1); CHANGELOG migration note (ARC-04-S14, ARC-09-S02); the optional npm channel publishes as a new major under the new record `@farstic/snowarch` (ARC-09-S10) |
| R-04 | Plaintext-at-rest credentials (one 0600 file) may not satisfy a client security team | D-04; keychain backend and client-credentials grant on the roadmap; prod defaults to read-only; audit log |
| R-05 | First live session's MCP output may exceed Claude Code's 25,000-token cap on wide tables | `maxRecords` 100 pinned; `_meta["anthropic/maxResultSizeChars"]` considered per tool in ARC-04 |
| R-06 | Skill auto-routing regression when 18 descriptions are rewritten to ≤ 500 chars | S-13 plus a full VALIDATION-TESTS run before 1.0 |
| R-07 | Users who ran the old setup keep stale `servicenow-mcp` / `nowaikit` entries with plaintext secrets in `~/.claude.json` and its `.bak-*` files | Doctor detects and prints the exact `claude mcp remove` commands and the backup-file reminder; ARC-10 checklist |

| R-12 | Scope cuts remove features somebody relies on (desktop app, other clients, prompts) | D-03; history preserved in the archived repositories |
| R-13 | `enabledMcpjsonServers` semantics change in a future Claude Code release | The doctor checks `claude mcp get servicenow` status text; a floor bump plus a documented approval click is the fallback |
