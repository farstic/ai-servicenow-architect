Install the AI Architect on Windows

This guide takes you from a Windows computer with nothing installed to a working AI Architect connected to your ServiceNow instance. Follow it from top to bottom. Every command has a Copy button. Plan about 30 minutes; most of it is waiting.

Before you begin

How to use this guide

  • Each dark box with a Copy button holds one command. The square on its left ticks itself when you copy, so you can see where you are.
  • Click Copy, click inside the PowerShell window, paste with a right-click (or Ctrl+V) and press Enter.
  • Wait until the line that starts with PS comes back before you run the next command.
  • Dark boxes labelled On screen show what you will see. You do not type those. Press ▶ Play to watch them typed out.
  • The screens in this guide are examples. Your version numbers, file counts, times, folders and free disk space differ.
Never paste several commands at once

Paste one command, press Enter, wait, then the next. In our own test a pasted block of three lines arrived broken and PowerShell asked a question nobody expected.

Something unexpected on the screen?

Do not press Enter. Press Ctrl+C to cancel, then look it up in If something goes wrong.

1
Step 1

Open PowerShell the normal way

PowerShell is the window where you type the commands in this guide.

  1. Press Win+R (the Windows logo key and R together). A small Run box opens.
  2. Type powershell and press Enter. Do not press Ctrl+Shift+Enter, and do not choose Run as administrator.
  3. Look at the line where you type. It must start with PS C:\Users\ followed by your user name.
If it shows PS C:\WINDOWS\system32>

That is an administrator window. Close it and start again from 1. Files made from an administrator window may not be changeable later from a normal one, and everything the AI Architect runs from that window would run with full rights over the computer.

To be completely sure, run this check. It only reads.

Medium Mandatory Level means a normal window, which is what you want. High Mandatory Level means an administrator window: close it.

A line saying Cannot load PSReadline module at the top of the window is harmless.

You need three programs (Git, Node.js and Claude Code), plus draw.io Desktop for the diagrams in your Word documents (2f). You install them once per computer. Each download command fetches one file from that program's official site.

No administrator rights needed

Every program goes into your own user folder (%LOCALAPPDATA%\Programs), so Windows never asks for an administrator password. Do not use winget for this guide: on many company computers it is broken or blocked, and its installers ask for administrator rights.

Step 3

Sign in to Claude Code

You do this once per computer.

  1. Claude Code opens a short first-time setup in the window. Choose any colour theme, then choose to sign in with your Claude account.
  2. Your browser opens. Sign in with your Claude account and allow access.
  3. Go back to PowerShell. If Claude Code asks whether you trust this folder, answer Yes.
  4. Type /exit and press Enter. You are back at the PS line.
4
Step 4

Download the AI Architect

This puts the AI Architect in a folder named AI-Arch inside your own user folder: C:\Users\<you>\AI-Arch. Run the three commands one at a time.

The warning: … is not a commit! line is harmless. Your line should now end in \AI-Arch>.

Why this folder

The installer keeps your ServiceNow password in a file inside this folder (.local\instances.json) and locks that file, and the folder .local around it, so that only your account and the system can read them. It does this in whatever folder you choose, and the wizard says so when it saves; if that folder had let other accounts read the file, the wizard adds a line saying who could, and that the permissions were changed just now. Your user folder is private to you anyway, so it is the one this guide uses. If you prefer another folder, use its name in these commands and in Every day. A folder name with a space in it has not been tested.

If git says the folder already exists, you already have a copy. Either continue with Step 5 in that folder, or pick another name and use it in both of the last two commands.

What to type
The user name and password you use to log in to this instance in the browser. On a PDI the user name is admin.
The password

What happens
The installer signs in and reads a few tables to learn what your account may do. It changes nothing on the instance.
What to type
Nothing. The [INFO] lines are normal.
If it fails
The message says why. Most often the address, user name or password has a typo. Nothing has been saved: press Ctrl+C and run .\bootstrap.cmd again.
7/7

Permissions

What it is
Which kinds of changes the AI Architect may make on this instance. [x] means allowed and [ ] means not allowed. probe: ok means your ServiceNow account is able to do it.
PermissionWhat it allows
WRITECreate, update and delete records: incidents, catalog items, users, update sets. Without it, everything is read-only.
CMDB_WRITEAlso write configuration items and their relationships in the CMDB. Needs WRITE.
SCRIPTINGWrite Script Includes, Business Rules, Client Scripts, ACLs and UI Actions. Reading them is always allowed. Needs WRITE.
ATFRun Automated Test Framework tests. Reading tests and results is always allowed.
NOW_ASSISTThe Now Assist (generative AI) tools. Needs a Now Assist licence on the instance.
FLUENTThe ServiceNow SDK (Fluent) build and deploy tools. Needs the ServiceNow SDK installed on this computer. If you do not use it, switch it off.

Not sure which to allow? Try the choices in the wizard practice above, or later with the permissions builder.

To accept the list as it is, press Enter.

To change one permission, for example to switch FLUENT off:

  1. Type its number, 6, and press Enter.
  2. The screen shows FLUENT: [1] on (current) [2] off. Type 2 and press Enter.
  3. The list comes back with [ ] FLUENT. Change others the same way, then press Enter to apply.

To choose a ready-made set, type preset, a space and its name, then press Enter:

PresetWhat is onWhen
fullEverythingProposed for pdi, dev and test instances.
pdi-developerEverything except NOW_ASSIST and FLUENTBuilding on a PDI, dev or test instance without the AI and SDK tools.
read-onlyNothingReviewing and designing against a real instance. The only choice for a prod instance.
customWhat you set by handShown automatically after you change single permissions.
The AI Architect always asks before it changes anything

Even with every permission on, before each change on your instance the AI Architect asks you a question of this form, and waits for your answer:

About to <action> on instance "pdi" — write approved?

Permissions only say what it may ask for. Changing them here is not an approval.

  • Mode: says live, with your instance label.
  • Next: names your folder. That is where you start Claude.

Press any key. You are back at the PS line.

Step 8

Start the AI Architect

Always start it from inside your AI-Arch folder.

  1. Claude asks whether you trust this folder. Answer Yes. It asks only the first time.
  2. Type /mcp and press Enter. Under you should see servicenow with a tick. Other lines come from your own Claude account and do not matter here. Press Esc.
  3. Type /snowarch status and press Enter. The first lines should match the end of the install:
  4. Ask a first question that only reads, for example How many open incidents are there? The AI Architect reads the answer from your instance and tells you what it read.
  5. Ask a first question, for example How do assignment rules work for incidents? In design-only mode the AI Architect answers from the ServiceNow documentation.

Uninstall

  1. In your folder, switch the AI Architect off. This is always safe.

Read once

Your data and safety

  • Your ServiceNow password is stored only in .local\instances.json inside your AI Architect folder. It never goes into the chat. Nobody helping you needs it, so never send that file.
  • The installer locks that file, and the folder .local around it, so that only your account and the system can read them (the computer's administrators can always take a file over). .\snowarch.cmd doctor checks it (check SV-02) and names anyone else who could read the file; .\snowarch.cmd doctor --fix repairs it after showing what it will change.
  • The AI Architect asks write approved? before every change on your instance, and a prod instance is saved read-only.
  • Your licence file is issued to you. Do not share it.
?
Read once

What has not been tested

This guide was written from one end-to-end install. Four things in it rest on something other than a run:

  • Windows 10. The test machine ran Windows 11. Windows 10 (version 1809 or later) has the same PowerShell 5.1 and takes the same commands.
  • Claude Code's first-run screens on Windows (Step 3). They are described in general terms because they change with Claude Code's releases.
  • A folder name with a space in it, a folder on a network drive, and a folder that OneDrive or another sync tool manages (Step 4).
  • What the screens say after the licence has ended (Step 7). The table is the product's own list of states, not a transcript of each one.

If you meet a difference, .\snowarch.cmd version and .\snowarch.cmd doctor (see Asking for help) are what to send.
