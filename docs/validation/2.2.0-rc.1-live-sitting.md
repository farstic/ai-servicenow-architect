## Observer notes

- **The tool's version came back without its link.** The version in `snow_ai_ai_agent_add`'s result listed no tools,
  and a re-read three seconds later listed the link. The tool read the version back before it wrote the links. This
  is ARC-09-C169, fixed in the pull request that carries this record; the Architect classified it as a repository
  defect and did not edit the repository itself.
- **`current_version` was populated.** The agent's configuration pointed at its version on this run, where the first
  trial on the same instance had seen it empty (PN-17).
- **The execution modes the instance stores** are `autopilot` for Autonomous and `copilot` for Supervised. Both were
  read from the instance, and the tool sent the one listed in `sys_choice`, never a default (PN-17).
- **Which read tools ran is not visible in the pastes.** The reconnaissance read AI agents and records without
  `INVALID_REQUEST`, but the pastes do not name the tools. So the ledger marks only the two `_add` tools from this
  record.
