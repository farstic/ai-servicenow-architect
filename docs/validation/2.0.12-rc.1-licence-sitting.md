## Observer notes

- **The first `.claude/settings.local.json` was malformed JSON from a paste.** Claude Code refused the file
  cleanly, and it was rewritten.
- **Under enforcement, the banner's `ok` line names no enforcement:**
  `Licence: ok · LIC-2026-0003 · until 2027-04-11`. That is by design: the word appears only with a state
  other than `ok`, and the C1 row now says so.
- **`issue` cannot stage `expired` on the day.** It refuses an end date before the issue date, so no licence
  can be issued already expired. The state is reached by waiting a day.
- **The ledger after the sitting:**
  - LIC-2026-0001: placeholder org, unused;
  - LIC-2026-0002: the creator's, perpetual;
  - LIC-2026-0003: revoked;
  - LIC-2026-0004: expiring on the day of the sitting;
