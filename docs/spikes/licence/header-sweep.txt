Each line carries the action ARC-01 takes and the story that owns it.  Story ownership in ARC-01:

    ARC-01-S01   founds the repository; adds the root LICENSE and NOTICE
    ARC-01-S02   imports the ENGINE working tree
    ARC-01-S03   imports the SERVER into packages/snowarch, applies the leaf-level D-03 cut,
                 renames the package and sets its `license` field

ARC-01-S08's own scope names exactly four items to edit (`packages/snowarch/LICENSE`,

verified in S08 — and engine `docs/README.md:157-159`) and three already deleted by S03.  This
sweep must, and does, cover all seven.  ARC-01-S08's acceptance criterion 1 is the test:

    git grep -n -i -E "source available|all rights reserved|not licensed for redistribution|license: MIT|SEE LICENSE IN LICENSE" \
        -- . ':!LICENSE' ':!packages/snowarch/LICENSE' ':!NOTICE'      # must print nothing


1. METHOD
---------
Pass 1 — the story's grep, over both trees:

    grep -rniE "proprietary|all rights reserved|source.available|license: MIT|not licensed for redistribution" \
         ~/work/AI-Architect-Claude ~/work/snow-mcp \
         --include=*.md --include=*.ts --include=*.mjs --include=*.yaml --include=*.json -l

Exclusions applied to pass 1, with the reason and the suppressed count:

    --exclude-dir=ServiceNowDocs   57 files in the engine.  Third-party vendored corpus (Apache-2.0,
                                   attributed in NOTICE), not a licence assertion by either source
                                   tree.  It is a submodule; ARC-03 owns it.
    --exclude-dir=node_modules    119 files in snow-mcp.  Dependency licences, never imported.
    --exclude-dir=.git             not source.
    --exclude-dir=dist            build output; ARC-04-S13 regenerates it.
    --exclude-dir=desktop         cut by D-03 item (1) and by ARC-01-S03's leaf cut; nothing imported.
                                  Its hits are still listed in §4 so no reader has to wonder.

Pass 1 is not sufficient — it provably cannot see three of the seven items (an extensionless file,
a licence section with no matched phrase, and an HTML licence badge).  Three further passes were run:

    Pass 2   `git grep` over ALL tracked files with no --include filter, both trees.
    Pass 3   a filename pass for LICENCE / LICENSE / COPYING / NOTICE / TERMS files.
    Pass 4   a semantic pass for licence statements the five patterns cannot match:
             `## License` headings, `©` / `(c)` copyright lines, and bare "MIT" in markup.
