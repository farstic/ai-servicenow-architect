# Validation runs

Evidence from sessions that were actually run, one file per story or test. A criterion whose proof
is "a model behaved correctly once" needs the transcript kept, because nothing in CI re-checks it.

What belongs here: the command, the CLI version, the session's answer in the part that matters, and
the verdict against the criterion as written — including where the criterion itself turned out to be
wrong. What does not: anything naming a real instance, user or credential.
